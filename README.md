# 放課後キャンパスクラブ ダッシュボード：取扱説明書

本プロジェクトは、小学生が日々の学習成果を楽しく記録し、所有感と達成感を味わえるように設計されたリッチなUIの学習記録アプリです。

## 1. システム概要

生徒がタイピングやマインクラフト（Minecraft）で制作した成果を、先生が「カード」として発行し、生徒がそれを「ガチャ」で手に入れることで、自分の「マイデッキ」や「作品展示」を充実させていくサイクルを提供します。

- **認証:** 起動時はログイン画面です。**先生**はメールアドレスとパスワード、**生徒**はログインID（例: `student-1`）とパスワードでログインします。Supabase を設定している場合はクラウド認証、未設定時はモックで動作します。
- **データ:** Supabase 設定時は認証・データベース・Storage で共有。未設定時はブラウザ内（LocalStorage / IndexedDB）とモックデータでスタンドアロン動作します。

---

## 2. 起動方法

```bash
npm install
npm run dev
```

ブラウザで表示されたURL（例: `http://localhost:5173`）にアクセスしてください。本番用ビルドは `npm run build`、プレビューは `npm run preview` です。

## 3. 管理者（先生）向け機能

管理画面（`/admin`）では、生徒ごとの学習データの入力とカードの発行を行います。

### ⌨️ タイピングデータの登録

生徒のタイピング練習の結果を入力します。

- **日付・スコア・WPM** を入力。前回比（前回スコアとの差）は自動計算され、生徒の「やる気メーター」や統計に反映されます。
- 下書き保存・保存時の Toast 通知に対応しています。

### 🎮 マインクラフト成果物の登録（重要）

生徒が制作した Minecraft 作品を登録します。このタブから登録すると、次の2つが同時に行われます。

1. **作品の記録**: 生徒の「作品ポートフォリオ」に 3D モデル（.glb）、スクリーンショット、MakeCode URL、説明文を保存します。
2. **カードの自動生成**: 作品をモチーフにしたカードを自動生成し、生徒のガチャ待ちリストに追加します。
   - カード名は作品名、カード画像はスクリーンショットが自動採用されます。
   - **レアリティ**は C〜UR から選択可能（初期値は R）です。

### 🎴 カード生成（手動）

Minecraft 作品に限らず、特別なご褒美や表彰としてカードを自由に発行できます。

- 画像、タイトル、レアリティ（C〜UR）、先生からのコメントを設定可能です。
- 生成されたカードは、生徒がガチャを回すと排出されます。プレビューでレアリティ演出を確認しながら作成できます。

### 👥 生徒の追加とAIアイコン生成

管理画面のトップページから新しい生徒を追加できます。同時に AI（Gemini）を使って生徒のアイコンを生成できます。

#### 🎨 良いアイコンを作るためのコツ

- **キーワードで伝える**: 文章より「単語」を並べると特徴が伝わりやすくなります。
  - **良い例**: `魔法使い, 赤い帽子, メガネ`
  - **惜しい例**: `赤い帽子をかぶっていて、メガネをかけた魔法使い`
- **性別に頼る**: 男の子・女の子の選択でベースの見た目が最適化されます。
- **見た目に集中する**: 「青い服」「剣」「ヘッドフォン」など、目に見える特徴を入力するのがコツです。

## 4. 生徒向け機能

生徒はログイン後、自分のダッシュボード（`/student/自分のログインID`）で成長を視覚的に楽しめます。画面下部のタブで **ホーム・ガチャ・マイデッキ・まいんくらふと** を切り替えます。

### 🏠 ホーム画面

- **今日のやる気**: タイピングの改善度（最近3回の前回比）、カード獲得数、**過去30日間の活動日数**、未開封カードの有無から算出されるやる気メーター（0〜100）です。週1回の活動を想定し、活動頻度は過去30日間で集計しています。
- **統計情報**: タイピングの最高スコアや集めたカードの枚数・最高レアリティを一目で確認できます。
- **ガチャ通知**: 先生から新しいカードが届くと、ガチャタブに未開封枚数のバッジが表示されます。

### 🎰 ガチャマシン

先生が発行したカードを引くための演出付きセクションです。

- レアリティ（C 〜 UR）に応じて演出が変化し、高レアでは紙吹雪（canvas-confetti）が発生します。
- 引いたカードは「マイデッキ」に保存されます。

### 📚 マイデッキ（カードギャラリー）

手に入れたカードのコレクションです。

- **3Dティルト効果**: マウスやタッチに合わせてカードが傾き、高レアは光沢・パーティクル付きで表示されます。
- **フィルタ**: レアリティ・種類（タイピング / Minecraft）・日付・キーワードで検索できます。
- カードをタップすると詳細（タイピングスコア・WPM・前回比、または 3D モデル・MakeCode URL 等）を表示します。

### 🧱 まいんくらふと（展示室）

自分の Minecraft 作品を 3D で閲覧できるギャラリーです。

- **表示条件**: その作品のカードをガチャで**開封（ゲット）**した後に表示されます。
- **3Dビューアー**: 登録された .glb を `model-viewer` で表示。ドラッグで回転、ホイールでズームできます。

## 5. 技術仕様とデータ保存

### 動作モード

- **Supabase 設定時**: 認証（メール/パスワード・ロール管理）、profiles / cards / minecraft_works テーブル、Storage（画像・.glb）でデータを共有。管理画面の「🔌 Supabase接続テスト」で同期・接続を確認できます。
- **Supabase 未設定時**: スタンドアロンで、ブラウザ内にデータを保存します。
  - **LocalStorage**: 下書き、キャッシュ、モック用のテキストデータなど。
  - **IndexedDB**: 3D モデル（.glb）や画像など容量の大きい資産。`idb://...` スキームでコンポーネント間参照します。

### カード枠画像

管理画面・生徒画面で RR/SR/UR カードの枠を表示するには、`public/images/frames/` に `RR.png`・`SR.png`・`UR.png` を配置してください。TCG ジェネレータ（`scripts/tcg_generator/`）で作成した枠をここにコピーすると反映されます。

### 作品が表示されない時のチェックリスト

1. **管理画面から登録したか？**: 「カード生成」タブではなく、**「マインクラフト成果物」タブ**から登録してください。
2. **ガチャを回したか？**: 「まいんくらふと」タブは、その作品のカードをガチャで開封するまで表示されません。

## 6. Supabase 接続（オプション）

先生用・生徒用でデータを共有する場合は、Supabase を利用できます。

### 設定手順

1. [Supabase](https://supabase.com/) でプロジェクトを作成する。
2. プロジェクトの **Settings → API** で **Project URL** と **anon (public) key** をコピーする。
3. プロジェクトルートに `.env` を作成し、`.env.example` を参考に次の2つを設定する。
   - `VITE_SUPABASE_URL` … Project URL  
   - `VITE_SUPABASE_ANON_KEY` … anon key  
4. 開発サーバーを再起動する（`npm run dev`）。
5. 管理画面の **「🔌 Supabase接続テスト」** から接続を確認する。

データベースは `supabase/schema.sql` を SQL Editor で実行して作成します。マイグレーションは `supabase/migrations/`、ストレージ設定は `supabase/storage.sql` を参照してください。
