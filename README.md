# 放課後キャンパスクラブ ダッシュボード：取扱説明書

本プロジェクトは、小学生が日々の学習成果を楽しく記録し、所有感と達成感を味わえるように設計されたリッチなUIの学習記録アプリです。

## 1. システム概要
生徒がタイピングやマインクラフト（Minecraft）で制作した成果を、先生が「カード」として発行し、生徒がそれを「ガチャ」で手に入れることで、自分の「マイデッキ」や「作品展示」を充実させていくサイクルを提供します。

---

## 2. 管理者（先生）向け機能
管理画面では、生徒ごとの学習データの入力とカードの発行を行います。

### ⌨️ タイピングデータの登録
生徒のタイピング練習の結果を入力します。
- スコア、WPM（速度）、前回比などを記録し、生徒の統計情報に反映されます。

### 🎮 マインクラフト成果物の登録（重要）
生徒が制作したMinecraft作品を登録します。このタブから登録すると、以下の2つが同時に行われます。
1. **作品の記録**: 生徒の「作品ポートフォリオ」に3Dモデル（.glb）、スクリーンショット、MakeCode URL、説明文を保存します。
2. **カードの自動生成**: 作品をモチーフにした**限定カード（レアリティR固定）**を自動的に生成し、生徒のガチャ待ちリストに追加します。
   - ※カード名は作品名、カード画像はスクリーンショットが自動採用されます。

### 🎴 カード生成（手動）
Minecraft作品に限らず、特別なご褒美や表彰としてカードを自由に発行できます。
- 好きな画像、タイトル、レアリティ（C〜UR）、先生からのコメントを設定可能です。
- 生成されたカードは、生徒が次回ログインした際にガチャとして出現します。

---

## 3. 生徒向け機能
生徒はダッシュボードを通じて、自分の成長を視覚的に楽しむことができます。

### 🏠 ホーム画面
- **今日のやる気**: ログイン状況や活動に応じて変化するやる気メーターです。
- **統計情報**: タイピングの最高スコアや集めたカードの枚数を一目で確認できます。
- **ガチャ通知**: 先生から新しいカードが届くと、通知バッジが表示されます。

### 🎰 ガチャマシン
先生が発行したカードを引くための特別な演出セクションです。
- レアリティに応じて演出が豪華になり、最高レアリティでは金色の演出と紙吹雪が発生します。
- 引いたカードは「マイデッキ」に保存されます。

### 📚 マイデッキ（カードギャラリー）
手に入れたカードをコレクションする場所です。
- **3Dティルト効果**: マウスやスマートフォンの傾きに合わせて、本物のトレカのようにキラキラと反射し、傾きます。
- **フィルタ機能**: レアリティや日付、キーワードでカードを検索できます。

### 🧱 まいんくらふと（展示室）
自分のMinecraft作品を3Dで自由に眺めることができるギャラリーです。
- **表示条件**: ガチャでその作品のカードを**開封（ゲット）**した後に、自動的に表示されます。
- **3Dビューアー**: 登録された.glbファイルを読み込み、ドラッグで回転、ホイールでズームが可能です。

---

## 4. 技術仕様とデータ保存
本アプリはスタンドアロンで動作し、ブラウザ内にデータを保存します。

- **LocalStorage**: 生徒のステータス、タイピング履歴、カードの設定データなどのテキスト情報を保存します。
- **IndexedDB**: 容量の大きい3Dモデル（.glbファイル）や高画質なスクリーンショット画像を安全に保存します。
- **資産の参照**: `idb://...` という特殊なスキームを使用して、データベース内のバイナリデータをコンポーネント間で共有します。

### 作品が表示されない時のチェックリスト
1. **管理画面から登録したか？**: 「カード生成」タブではなく、必ず「マインクラフト成果物」タブから登録してください。
2. **ガチャを回したか？**: 児童画面の「まいんくらふと」タブは、その作品のカードがガチャから排出（開封）されるまで表示されない仕様です。
