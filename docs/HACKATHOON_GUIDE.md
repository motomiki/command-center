ハッカソン運営者から指定されているツールの一覧を、「アプリケーション実行プロダクト」「AI技術」「その他の技術」の3つのカテゴリにまとめてノートを作成しました。

Cursor Agent でのツール選定や開発にご活用ください。

### ハッカソン指定ツール一覧

**1. (必須) Google Cloud アプリケーション実行プロダクト**
以下のいずれか1つ以上を使用する必要があります。

* **Cloud Run**
* **App Engine**
* **Cloud Functions (旧 Cloud Functions)**
* **Google Compute Engine**
* **Google Kubernetes Engine (GKE)**
* **Cloud TPU / GPU**

**2. (必須) Google Cloud AI 技術**
以下のいずれか1つ以上を使用する必要があります。

* **Gemini API** (Vertex AI経由の利用を推奨)
* **Vertex AI** (AutoML, Vector Search, Explainable AI等)
* **Agent Builder**
* **ADK (Agents Development Kit)**
* **Gemma** / **Imagen**
* **各種 AI API** (Speech-to-Text, Vision AI, Natural Language, Translation)

**3. (任意) その他の技術**
プロジェクトに応じて利用可能です。

* **Flutter**
* **Firebase**
* **Veo**
